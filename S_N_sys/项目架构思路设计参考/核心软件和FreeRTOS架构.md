【板子2：边缘网关 (Gateway)】 —— 负责汇聚数据，转发至PC端与云端
================================================================================================
                                    [LoRa 模块]
                                        │ (UART 接收)
                                        ▼
     ┌────────────────────────────────────────────────────────────────────────┐
     │ 【中断】ISR: UART_DMA_IDLE_IRQHandler (串口DMA+空闲中断)                │
     │ 运行机制：DMA自动搬数据，空闲中断触发后，仅做一件事：osSemaphoreRelease()    │
     └────────────────────────────────────┬───────────────────────────────────┘
                                          │ 释放信号量
                                          ▼
                            ╔═══════════════════════╗
                            ║  Sem1 (二值信号量)    ║
                            ╚═══════════════════════╝
                                          │ 获取信号量
                                          ▼
   ┌──────────────────────────────────────────────────────────────────────────┐
   │ 【任务4】CommRxTask (接收解析任务) - 优先级: 高(4)                          │
   │ 运行机制：拿到信号量 → 读取DMA缓冲区 → 状态机逐字节扫描（找帧头、验长度）  │
   │           → CRC16校验通过 → 提取出完整的数据包                             │
   └────────────────────────────────────┬─────────────────────────────────────┘
                                        │ 发送消息 (解析后的数据)
                                        ▼
                            ╔═══════════════════════╗
                            ║   Queue3 (转发队列)   ║
                            ╚═══════════════════════╝
                                        │ 接收消息
                                        ▼
   ┌──────────────────────────────────────────────────────────────────────────┐
   │ 【任务5】ForwardTask (转发任务) - 优先级: 中低(2)                           │
   │ 运行机制：把数据转发到两个地方：                                             │
   │  ① 通过UART2发给电脑的Qt上位机（QSerialPort）                              │
   │  ② 通过UART3发AT指令给ESP8266，走MQTT上巴法云                             │
   └────────────────────────────────────┬─────────────────────────────────────┘
                                        │
                         ┌──────────────┴──────────────┐
                         ▼                             ▼
                 [USB转TTL 到PC]               [ESP8266 WiFi模块]

【底层系统支撑】 —— 支撑上述任务运行的基础
================================================================================================
   ┌──────────────────────────────────────────────────────────────────────────┐
   │ 【任务6】MonitorTask (监控任务) - 优先级: 最高(5)                           │
   │ 运行机制：定时喂狗(IWDG)，检查其他任务的标志位，防止任务卡死。                 │
   ├──────────────────────────────────────────────────────────────────────────┤
   │ 【任务7】Idle Task (空闲任务) - 优先级: 最低(0)                             │
   │ 运行机制：进入 Tickless 低功耗模式，节省电池电量。                            │
   ├──────────────────────────────────────────────────────────────────────────┤
   │ 【互斥锁 Mutex】保护共享资源：I2C总线、SPI总线、串口打印(UART1)。          │
   │ 原因：防止多个任务同时使用同一硬件导致数据错乱（优先级反转）。                  │
   └──────────────────────────────────────────────────────────────────────────┘
