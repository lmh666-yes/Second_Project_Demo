## 1. 设计定位

采集精密仪器实验室的环境参数（温湿度 / 气压 / 光照 / 空气质量），
经滤波与阈值判断后打包，通过 LoRa 无线发送至边缘网关（板2）。

- 职责一 : 多传感器高精度采集、数据校验与滤波
- 职责二 : 环境异常本地告警（蜂鸣器 / OLED 提示）
- 职责三 : 按固定周期组帧发送（LoRa 上行）

## 4. 软件架构（FreeRTOS）

> 与《核心软件和FreeRTOS架构.md》一致；任务与优先级以下表为准。

### 4.1 任务表

| 任务 | 优先级 | 周期 / 触发 | 职责 |
|---|---|---|---|
| SensorTask（采集） | 中（3） | osDelayUntil 严格周期 | 读 SHT30 / BMP280 / BH1750 / CCS811 / MQ-135，发 Queue1 |
| ProcessTask（处理） | 中（3） | Queue1 触发 | 滤波（中值 / 滑动）、阈值判断、告警、打包，发 Queue2 |
| CommTask（通信） | 高（4） | Queue2 触发 | 组帧（帧头 / 长度 / 校验）→ 串口发 LoRa |
| MonitorTask（监控） | 最高（5） | 1 s | 喂狗 / 任务心跳检查（sys_wdg 心跳版） |

### 4.2 队列与同步

| 对象 | 类型 | 生产者 → 消费者 | 说明 |
|---|---|---|---|
| Queue1 | 消息队列 | SensorTask → ProcessTask | 单次原始数据 |
| Queue2 | 消息队列 | ProcessTask → CommTask | 处理后的待发数据 |
| Mutex | 互斥锁 | 多任务共用 I2C1 | 保护 I2C 总线 |
| 心跳位带 | 标志位 | 各任务 → MonitorTask | SYS_WDG_Heartbeat |

### 4.3 数据流

```mermaid
flowchart LR
    A["传感器硬件"] --"I2C / SPI / ADC"--> B["SensorTask 优先级3"]
    B --"Queue1 原始数据"--> C["ProcessTask 优先级3"]
    C --"滤波 / 阈值 / 打包"--> D["Queue2 待发数据"]
    D --"出队"--> E["CommTask 优先级4"]
    E --"UART 帧"--> F["LoRa E22 无线发送"]
```

## 5. 通信协议（LoRa 上行帧）

> 与网关端保持一致；优先复用库模块 sys_frame（帧头 0xAA / 帧尾 0x55）。

| 字段 | 长度 | 值 / 说明 | 状态 |
|---|---|---|---|
| 帧头 | 1 | 0xAA | 与 sys_frame 一致 |
| 命令 | 1 | 0x01 = 环境数据上报 | 待定 |
| 长度 | 1 | 数据段字节数 | 待定 |
| 数据 | n | 见 5.1 数据段定义 | 待定 |
| 校验 | 1 | 异或（sys_frame 默认）或 CRC16 | 待定 |
| 帧尾 | 1 | 0x55 | 与 sys_frame 一致 |

| 序号 | 参数 | 字节数 | 编码 | 单位 |
