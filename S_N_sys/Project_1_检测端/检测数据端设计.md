## 1. 设计定位

采集精密仪器实验室的环境参数（温湿度 / 气压 / 光照 / 空气质量），
经滤波与阈值判断后打包，通过 LoRa 无线发送至边缘网关（板2）。

- 职责一 : 多传感器高精度采集、数据校验与滤波
- 职责二 : 环境异常本地告警（蜂鸣器 / OLED 提示）
- 职责三 : 按固定周期组帧发送（LoRa 上行）

## 4. 软件架构（FreeRTOS）

> 与《核心软件和FreeRTOS架构.md》一致；任务与优先级以下表为准。

### 4.1 任务表

| 任务 | 优先级 | 周期 / 触发 | 职责 |
|---|---|---|---|
| SensorTask（采集） | 中（3） | osDelayUntil 严格周期 | 读 SHT30 / BMP280 / BH1750 / CCS811（I2C）+ 读 MQ-135 的 DMA 缓冲，发 Queue1 |
| ProcessTask（处理） | 中（3） | Queue1 触发 | 滤波（中值 / 滑动）、阈值判断、告警、打包，发 Queue2 |
| CommTask（通信） | 高（4） | Queue2 触发 | 组帧（帧头 / 长度 / 校验）→ 串口发 LoRa |
| MonitorTask（监控） | 最高（5） | 1 s | 喂狗 / 任务心跳检查（sys_wdg 心跳版） |

> MQ-135 读取方式 : ADC + DMA 循环模式（DMA_Mode_Circular，后台自动刷新数组），
> SensorTask 只读数组、不做阻塞式轮询——周期任务不会被 ADC 等待拖慢。
> （库模块 : sys_adc 的 DmaScanInit / DmaTimerTrigInit）

### 4.2 队列与同步

| 对象 | 类型 | 生产者 → 消费者 | 说明 |
|---|---|---|---|
| Queue1 | 消息队列 | SensorTask → ProcessTask | 单次原始数据 |
| Queue2 | 消息队列 | ProcessTask → CommTask | 处理后的待发数据 |
| Mutex | 互斥锁 | 多任务共用 I2C1 | 保护 I2C 总线 |
| 心跳位带 | 标志位 | 各任务 → MonitorTask | SYS_WDG_Heartbeat |

### 4.3 数据流

```mermaid
flowchart LR
    A["传感器硬件"] --"I2C / ADC"--> B["SensorTask 优先级3"]
    B --"Queue1 原始数据"--> C["ProcessTask 优先级3"]
    C --"滤波 / 阈值 / 打包"--> D["Queue2 待发数据"]
    D --"出队"--> E["CommTask 优先级4"]
    E --"UART 帧"--> F["LoRa E22 无线发送"]
```

## 5. 通信协议（LoRa 上行帧 · 已定案 2026-09-28）

> 定案说明 : 板1 → 板2 → Qt 全程使用同一种二进制帧（Qt 端直接解析原帧，不做格式转换）；
> 校验用 CRC16-MODBUS（库内已有现成实现，见 modbus 模块）；
> 板1 / 板2 / Qt 三端实现必须与本表完全一致。

| 字段 | 字节数 | 值 / 说明 |
|---|---|---|
| 帧头 | 2 | 0xAA 0x55（固定） |
| 命令 | 1 | 0x01 = 环境数据上报 |
| 长度 | 1 | 数据段字节数（本帧 = 0x0C，12 字节） |
| 数据段 | 12 | 见 5.1 数据段定义 |
| CRC16 | 2 | CRC16-MODBUS；范围 = 命令 + 长度 + 数据段（不含帧头 / 帧尾）；低字节在前 |
| 帧尾 | 2 | 0x55 0xAA（固定） |

> 整帧长度 = 2 + 1 + 1 + 12 + 2 + 2 = 20 字节。
> 组帧方式 : 手动移位拼接（不用结构体强转，避免字节对齐差异）。

### 5.1 数据段定义（12 字节 · 已定案）

| 帧内偏移 | 参数 | 字节数 | 编码（大端：高字节在前） | 示例 |
|---|---|---|---|---|
| 4 | 温度 | 2 | 有符号 short，放大 10 倍（℃ x10） | 25.3℃ → 253 = 0x00FD |
| 6 | 湿度 | 2 | 无符号 short，放大 10 倍（%RH x10） | 48.5% → 485 = 0x01E5 |
| 8 | 气压 | 2 | 无符号 short，放大 10 倍（hPa x10） | 1013.2 → 10132 = 0x2794 |
| 10 | 光照 | 2 | 无符号 short，原值（lx） | 500 = 0x01F4 |
| 12 | TVOC（CCS811） | 2 | 无符号 short，原值（ppb） | 50 = 0x0032 |
| 14 | MQ-135 原始值 | 2 | 无符号 short，ADC 12 位原始值 | 1234 = 0x04D2 |

> 解析示例 : 温度 = (short)((data[4] << 8) | data[5]) / 10.0
> 有符号值说明 : -5.0℃ → -50 → 0xFFCE（按 short 解释）。
