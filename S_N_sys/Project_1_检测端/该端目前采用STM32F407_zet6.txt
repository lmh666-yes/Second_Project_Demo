## 1. 主控与工程配置

| 项目 | 值 |
|---|---|
| MCU | STM32F407**ZET6**（LQFP144，512KB Flash / 192KB SRAM + 64KB CCM） |
| Keil 工程 | `S_N_sys\Project_1_检测端\Project\标准模板.uvprojx` |
| Keil Device | STM32F407ZE |
| 编译宏 | `USE_STDPERIPH_DRIVER, STM32F40_41xxx, HSE_VALUE=8000000` |
| 外部晶振 | 8 MHz（HSE） |
| 库 | ST 标准外设库（SPL）+ FreeRTOS（已挂入工程） |
| 编译状态 | **0 Error / 3 Warning**（3 条为 main.c 未使用变量，无害） |

> 512KB Flash 意味着只能擦写 `FLASH_Sector_0 ~ 7`；参数保存不要用 Sector_8 以上（ZE 芯片上不存在）。

## 3. 与目标项目的匹配结论

| 项目需要 | 板1 是否具备 | 结论 |
|---|---|---|
| SHT30 温湿度（I2C） | I2C 总线可用（板载 MPU6050、EEPROM 都在 I2C 上，说明已引出） | 可接 |
| BH1750 光照（I2C） | 同上，可挂同一条 I2C 总线 | 可接 |
| CCS811 空气质量（I2C） | 同上 | 可接 |
| BMP280 气压（I2C） | 同上 | 可接 |
| OLED SSD1306（I2C） | I2C 可用；工程已有 `sys_oled.c/.h` | 可接 |
| MQ-135（ADC） | **有专门 ADC 输入接口**，工程已有 `sys_adc`（含 `SYS_ADC_DmaScanInit`） | 可接 |
| LoRa E22（UART） | **有「无线收发模块接口」+ UART1/2/3 引出**，工程已有 `sys_usart`（DMA+空闲中断） | 可接 |
| 本地告警 | **板载有源蜂鸣器**（`BEEP` 网表） | 已有 |
| 调试串口 | **板载 CH340G**，USB 一线连电脑 | 已有 |

> **结论：板1 硬件资源充足，目标项目所需模块全部能接，无需额外扩展板。**

> 特别提示：板1 **已板载 DHT11 温湿度传感器**。虽然精度不如 SHT30，
> 但可以先用它把「采集任务 → 队列 → 处理任务」这条 FreeRTOS 链路跑通，
> 等 SHT30 到货只需替换传感器读取函数，主框架不用动。

## 4. 引脚接线表（待核对后定稿）

> **本节需你核对实物后填写。**
> 原理图中连接器的引脚名是以矢量图形绘制的（非文本），
> 无法自动读出"哪个排针的第几脚 = 哪个 GPIO"，只能人工对照原理图/实物确认。

### 4.1 填写原则

1. 以**模块库头文件「区块 1」**的配置为准，改完代码再回填本表；
2. 一行格式：`功能 → 引脚（外设，备注）`，
   例：`I2C1_SCL → PB6（I2C1，400kHz，接全部 I2C 模块 SCL）`。

### 4.3 I2C 总线共用注意事项

4 个 I2C 传感器 + OLED 共用一条 I2C1 总线时：

1. **上拉电阻**：整条总线只需一组上拉（通常 4.7kΩ）。若模块自带上拉，不要重复堆叠——
   多个模块并联上拉会让等效阻值过小（< 1kΩ），导致总线拉不高、通信失败。
2. **地址不能冲突**：本项目 0x44（SHT30）/ 0x23（BH1750）/ 0x3C（OLED）/ 0x76（BMP280）
   互不冲突；CCS811 需实测确认。
3. **FreeRTOS 下必须加互斥锁**：多个任务共用 I2C 时会互相打断传输，
   用 `xSemaphoreCreateMutex()` 保护（速查工具「流程卡 ⑧」有示例）。
4. **上电第一步先扫描**：用 `SYS_I2C_Scan()` 确认设备都在，再写具体驱动——
   能省掉一大半"读不出数据"的排查时间。

## 5. 板上可直接复用的工程驱动（FWLIB）

| 驱动 | 用途 | 与本项目关系 |
|---|---|---|
| `sys_i2c.c/.h` | 通用 I2C HAL（`ReadReg16`/`WriteReg16`/`Scan`/`IsDeviceReady`/`BusReset`） | 4 个 I2C 传感器的通信层 |
| `sys_spi.c/.h` | SPI 主机 | BMP280 备用（SPI 模式） |
| `sys_adc.c/.h` | ADC（含 DMA 扫描、连续、外部触发） | MQ-135 采集 |
| `sys_dma.c/.h` | DMA 搬运 | 串口/ADC 的 DMA 支撑 |
| `sys_usart.c/.h` | 串口（DMA + 空闲中断） | LoRa 收发 |
| `sys_oled.c/.h` | OLED SSD1306 | 本地显示 |
| `sys_tim.c/.h` | 定时器（含 PWM、输入捕获） | PWM / 蜂鸣器 / 测频 |
| `sys_rtc.c/.h` | RTC | 时间戳 |
| `sys_wdg.c/.h` | 看门狗（含心跳版） | MonitorTask 喂狗 |
| `sys_flash.c/.h` | 片内 Flash 读写 | 参数保存 |
| `sys_frame.c/.h` | 串口帧协议 | 与已定案 20 字节帧配合 |
| `sys_modbus.c/.h` | 含 CRC16-MODBUS 实现 | 协议校验（直接复用，保证三端一致） |
| `sys_softimer.c/.h` | 软件定时器 | 周期任务辅助 |
| `sys_fault.c/.h` | 硬件异常捕获 | 可靠性 |
| `sys_mpu6050.c/.h` | 六轴 | 板载，本项目暂不用 |
| `sys_dht11.c/.h` | DHT11 | 板载；可先用来跑通采集链路 |
