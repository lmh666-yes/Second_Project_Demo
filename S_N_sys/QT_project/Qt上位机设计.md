## 4. 通信协议对接（已定案：二进制帧 · 2026-09-28）

> 数据源 : 板2 透传板1 的完整二进制帧（见《数据传输端设计.md》第 5 节）；
> Qt 端按同一帧格式解析——原文本行方案（TEMP:...）作废。

### 4.1 帧解析状态机（必须实现）

串口数据是流式的——可能一次收到半个包，也可能一次收到三个包，
因此必须用 环形缓冲区（Ring Buffer） + 状态机：

1. 找帧头 : 扫描 0xAA 0x55
2. 读长度 : 1 字节（本协议固定 0x0C = 12）
3. 收数据 : 继续收满 长度 + 2（CRC） + 2（帧尾）字节
4. 校验   : CRC16-MODBUS（范围 = 命令 + 长度 + 数据）；失败 → 丢弃继续找帧头
5. 提取   : 按偏移解析各字段（见 4.2）

### 4.2 字段解析对照（帧内偏移 · 整帧 20 字节）

| 字段 | 帧内偏移 | 类型 | 换算 |
|---|---|---|---|
| 帧头 | 0 | 2B | 0xAA 0x55 |
| 命令 | 2 | 1B | 0x01 |
| 长度 | 3 | 1B | 0x0C |
| 温度 | 4 | short（大端） | 有符号，÷10 → ℃ |
| 湿度 | 6 | ushort（大端） | ÷10 → %RH |
| 气压 | 8 | ushort（大端） | ÷10 → hPa |
| 光照 | 10 | ushort（大端） | 原值 → lx |
| TVOC | 12 | ushort（大端） | 原值 → ppb |
| MQ-135 | 14 | ushort（大端） | ADC 原始值 |
| CRC16 | 16 | 2B | CRC16-MODBUS，低字节在前 |
| 帧尾 | 18 | 2B | 0x55 0xAA |

> 示例（C++）: `short t = (short)((data[4] << 8) | data[5]);  double temp = t / 10.0;`

### 5.1 绘图性能要点（多曲线上线前必做）

| 要点 | 做法 |
|---|---|
| 关闭抗锯齿 | 初始化时 `ui->widgetPlot->setNotAntialiasedElements(QCP::aeAll);`（曲线 / 点数一多，提速明显） |
| 批量刷新 | 不要每来一个点就 replot()；QTimer 每 50 ms 批量刷新一次（新点先入数据数组） |
| 滑动窗口 | 沿用现有 100 点窗口（或按需扩大），防止数据与绘制量无限增长 |

### 5.2 数据记录 / 导出（规划）

- 记录 : 每解析出一帧，按行追加 `时间,温度,湿度,气压,光照,TVOC,MQ-135`
- 导出 : 点击按钮后用 QFile + QTextStream 写出 `.csv`（UTF-8）
- 可选 : 定时自动保存 / 超行数滚动
