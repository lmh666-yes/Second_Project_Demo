## 1. 主控与工程配置

| 项目 | 值 |
|---|---|
| MCU | STM32F407**ZGT6**（LQFP144，**1MB** Flash / 192KB SRAM + 64KB CCM） |
| Keil 工程 | `S_N_sys\Project_2_数据通信端\Project\000标准模板库.uvprojx` |
| Keil Device | STM32F407ZG |
| 编译宏 | `USE_STDPERIPH_DRIVER, STM32F40_41xxx, HSE_VALUE=8000000` |
| 外部晶振 | 8 MHz（HSE） |
| 库 | ST 标准外设库（SPL）+ FreeRTOS（已挂入工程） |
| 编译状态 | **0 Error / 0 Warning**（FreeRTOS 内核 7 个文件全部编译进去） |

> ⚠ 与板1 的唯一实质区别：板2 是 **1MB Flash**，可擦写 `FLASH_Sector_0 ~ 11`。
> 参数区常放最后一个扇区 `FLASH_Sector_11`（如 `0x080E0000`）。
> 库函数层面两板 100% 通用，代码可互换（只需改 Keil Device 与 Flash 扇区号）。

## 3. 与目标项目的匹配结论

板2 作为**边缘网关**，需要：LoRa 接收 + 串口转发 Qt + ESP8266/MQTT 上云 + 看门狗。

| 项目需要 | 板2 是否具备 | 结论 |
|---|---|---|
| LoRa E22 接收（UART） | 有 **P11 排针**（TXD3/RXD3/PB10/PB11）和多个 UART 引出；工程已有 `sys_usart`（DMA+空闲中断） | ✅ 可接 |
| **ESP8266 WiFi** | 有 WiFi 模块接口；工程**已有 `esp8266.c/.h`（20 个 API）** | ✅ 已有 |
| **MQTT 客户端** | 工程**已有 `mqtt.c/.h`（14 个 API）** | ✅ 已有 |
| 串口转发 Qt 上位机 | 板载 CH340G + P9；工程已有 `sys_usart` | ✅ 已有 |
| 串口帧协议 | 工程**已有 `sys_frame.c/.h`**；CRC16-MODBUS 在 `modbus.c` | ✅ 已有 |
| 看门狗心跳 | 工程**已有 `sys_wdg.c/.h`（含心跳版）** | ✅ 已有 |
| 本地显示/调试 | LCD 接口、RGB 点阵、EEPROM | ✅ 可用 |

> **结论：板2 作为网关的资源完全足够，且 ESP8266 / MQTT / 帧协议 / 看门狗四个关键驱动工程里都已经有了** ——
> 板2 侧的主要工作是**写网关任务逻辑**（接收解析 → 双路转发），而不是从零写驱动。
>
> ⚠ **唯一硬缺口：LoRa E22 驱动两端都没有**（板1、板2 都要新增 `lora_e22.c/.h`）。

### 4.3 串口分配建议（三个串口同时用）

板2 需要**同时**跑：LoRa（收）、ESP8266（AT/MQTT）、Qt 上位机（转发），
建议按下列原则分配（具体引脚待你在库里核对后填）：

| 用途 | 建议外设 | 理由 |
|---|---|---|
| 调试打印 | USART1（PA9/PA10） | 板载 CH340G 固定在此，不占用其他资源 |
| LoRa E22 | USART2 或 USART3 | 二者都在 APB1，可用 DMA |
| ESP8266 | USART3 或 UART4/5 | 与 LoRa 错开；ESP8266 只跑 AT 指令，波特率 115200 |
| Qt 上位机 | UART4 / UART5 或 USART6 | 数据量大时可用 DMA 发送 |

> ⚠ 注意：**每个 USART 的 DMA 数据流/通道是固定映射的**，不能随便选。
> 查速查工具的「DMA 请求映射表」：
> `USART1_RX=DMA2_Stream5/通道4`、`USART2_RX=DMA1_Stream5/通道4`、
> `USART3_RX=DMA1_Stream1/通道4`、`USART6_RX=DMA2_Stream1/通道5`。

## 5. 板上可直接复用的工程驱动（FWLIB）

板2 的 FWLIB 是两板中最全的（43 个驱动），与网关直接相关的高亮如下：

| 驱动 | 用途 | 与本项目关系 |
|---|---|---|
| **`esp8266.c/.h`** | WiFi AT 指令驱动（20 个 API：Init/TestAT/SetMode/JoinAP/ConnectTCP/SendData…） | ★★ 网关上云核心，**已有** |
| **`mqtt.c/.h`** | MQTT 客户端（14 个 API：Connect/Publish/PublishInt/PublishFloat/PubllishStr/Ping/KeepAliveService…） | ★★ 巴法云上报，**已有** |
| `sys_usart.c/.h` | 串口（DMA + 空闲中断） | ★ LoRa / ESP8266 / Qt 三路串口 |
| `sys_frame.c/.h` | 串口帧协议 | ★ 20 字节帧收发 |
| **`modbus.c/.h`** | 含 **CRC16-MODBUS** 实现 | ★★ 协议校验（三端复用同一实现） |
| `sys_wdg.c/.h` | 看门狗（含心跳版） | ★ MonitorTask 喂狗 |
| `sys_i2c.c/.h` | 通用 I2C HAL | 传感器/EEPROM |
| `sys_adc.c/.h` / `sys_dac.c/.h` | ADC / DAC | 模拟量 |
| `sys_can.c/.h` | CAN | 板载 CAN 接口 |
| `sys_eth.c/.h` | 以太网 | 备用上行通道 |
| `sys_rtc.c/.h` | RTC | 时间戳 |
| `sys_flash.c/.h` / `w25qxx.c/.h` / `at24c02.c/.h` | 片内 Flash / SPI Flash / EEPROM | 参数与日志保存 |
| `sys_filter.c/.h` / `kalman.c/.h` | 滑动滤波 / 卡尔曼 | ★ 数据滤波（ProcessTask） |
| `sys_softimer.c/.h` | 软件定时器 | 周期任务 |
| `sys_str.c/.h` | 字符串处理 | AT 指令拼接 |
| `sys_fault.c/.h` | 硬件异常捕获 | 可靠性 |
