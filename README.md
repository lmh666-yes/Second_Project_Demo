# 精密仪器实验室环境监护系统

基于两块 STM32F407 开发板的分布式环境监测系统（综合设计项目）。

采集节点负责环境数据采集（温湿度、气压、光照、空气质量），经 LoRa 无线发送；边缘网关汇聚数据后转发至 Qt 上位机，并通过 ESP8266 + MQTT 上报巴法云。下位机基于 ST 标准外设库与 FreeRTOS（任务、队列、信号量）开发。

## 目录结构

| 目录 | 内容 |
|---|---|
| S_N_sys/项目架构思路设计参考 | 项目方案与软件架构文档 |
| S_N_sys/Project_1_检测端 | 采集节点 Keil 工程（STM32F407ZE） |
| S_N_sys/Project_2_数据通信端 | 边缘网关 Keil 工程（STM32F407ZG） |
| S_N_sys/QT_project | Qt 上位机工程（串口通信 + 曲线显示） |

根目录的 project_check.ps1 与 project_check.bat 为项目内容巡检脚本（生成 检查报告.md）。
