### 2026-10-19 · H3 重建链提速：去 gradle `clean` + assets 未变跳过重打 + 分环耗时

**病根**：`rebuild.bat` 第 7 环调 `gradlew clean assembleDebug` —— `clean` 让每次重打 APK 都从零编；
而这一环的**输出（手机版单文件 / assets）常常没变**（例如只改了工具箱代码、或只是重跑一遍链），
却照样全量重编；另外整条链跑完只报"DONE"，**不知道时间花在哪一环**。

**做法**：
- `构建APK.bat`：`gradlew clean assembleDebug` → **`gradlew assembleDebug`**（去掉 clean，走增量）。
  新增"内容未变就整环跳过"：`build_data.py` 比对手机版单文件与 `android/assets/index.html` 的
  sha256，且两个 APK 都在时，**退出码 2** 告知调用方无变化；`构建APK.bat` 见 2 就打印
  `[skip] mobile html unchanged - skip gradle rebuild.` 并跳到收尾（末尾补 `exit /b 0`，
  免得把 errorlevel=2 带出去让上层误判失败 —— 这是第一次改时踩到的坑）。
- `export_json.js`（配合 H2 的戳）：**数据没变就沿用原来的导出时间**（版本号一致 = 同一份数据），
  这样戳文件字节不变 → 手机版 / assets 不变 → 第 7 环才真的能命中"未变"。
- `rebuild.bat`：插入 `:tick` 子程序（纯 ASCII，按 `%TIME%` 算到百分秒），**每环跑完打印
  `[elapsed] N/8 <环节名> : X.XXs`**；`goto :done` 跳过子程序定义，不影响原流程。
  （中文 .bat 用 PowerShell 按 GBK 读写做**定点替换**，其余中文一字未动。）

**实测**（用 cmd 跑整链，即双击那条真实路径）：
- 完整链（assets 未变这条）**exit 0**，8 环耗时逐条打出：data checks 2.11s / web regression 0.52s /
  export 0.39s / baseline 1.00s / toolbox build 1.67s / selftest 4.91s / **mobile+APK 0.40s（[skip] 命中，没重打）** /
  sync check 0.76s；`check_sync.py` **20 通过 / 0 失败 / 0 跳过**。
- `/nodb` 路径同样 exit 0、8 个 `[elapsed]` 齐全。
- 复跑确认幂等：第二次 export 的戳仍是 `@ 2026-10-19 14:38`（时间沿用，未随重跑刷新）→
  `data_build_info.js` 字节不变 → 第 7 环稳定走"跳过"，`git status` 里也没有多余改动。
- **已知环境限制**（非本次引入）：从 PowerShell（控制台 cp65001）里跑 rebuild.bat 时，
  第 7 环用中文文件名 `call` 会找不到文件（cmd 按**启动时码页**解码 .bat 字节，`chcp 936` 来不及生效）；
  用 cmd 双击/启动（OEM cp936）正常。此行是原有写法，本次未改。
