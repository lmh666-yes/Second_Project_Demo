却照样全量重编；另外整条链跑完只报"DONE"，**不知道时间花在哪一环**。

**做法**：
- `构建APK.bat`：`gradlew clean assembleDebug` → **`gradlew assembleDebug`**（去掉 clean，走增量）。
  新增"内容未变就整环跳过"：`build_data.py` 比对手机版单文件与 `android/assets/index.html` 的
  sha256，且两个 APK 都在时，**退出码 2** 告知调用方无变化；`构建APK.bat` 见 2 就打印
  `[skip] mobile html unchanged - skip gradle rebuild.` 并跳到收尾（末尾补 `exit /b 0`，
  免得把 errorlevel=2 带出去让上层误判失败 —— 这是第一次改时踩到的坑）。
- `export_json.js`（配合 H2 的戳）：**数据没变就沿用原来的导出时间**（版本号一致 = 同一份数据），
  这样戳文件字节不变 → 手机版 / assets 不变 → 第 7 环才真的能命中"未变"。
- `rebuild.bat`：插入 `:tick` 子程序（纯 ASCII，按 `%TIME%` 算到百分秒），**每环跑完打印
  `[elapsed] N/8 <环节名> : X.XXs`**；`goto :done` 跳过子程序定义，不影响原流程。

### 2026-10-17 · 移植性修复（换台电脑能不能跑）
