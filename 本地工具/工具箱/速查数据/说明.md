# 速查数据（数据管线）

这里**不是工具，是数据**：桌面端「STM32 速查」页面跑的 `dataset.json` 及其配套脚本都在这里。
2026-10-15 从 `本地工具/STM32速查/` 搬进来——那个目录已删除，桌面端也早就并进了工具箱
（页面在 `工具箱\打开工具箱.bat` → 侧栏「查资料 → STM32 速查」）。

**网页版是唯一数据源**：`本地工具\标准库速查\`（`标准库函数速查.html` + 17 个 `data_*.js`）。
本目录里的 `dataset.json` 是**导出物**，不手改；改数据一律改网页那 17 个 `data_*.js`，
再跑一遍导出（下面的「整链」一条命令就够）。

## 目录结构

```
工具箱\速查数据\
├── data\
│   ├── dataset.json            导出物（1004 条，约 4MB；工具箱运行时读取，改了不用重编 exe）
│   └── search_baseline.txt     搜索基线（28 例，桌面 --selftest 逐行比对）
├── tools\
│   ├── export_json.js          导出（网页引擎当标准答案借壳跑一遍）；`--baseline` 重生成基线
│   └── rebuild.bat             **一键重建整条链**（见下）
├── rules\
│   └── freertos_isr_rules.json 中断上下文 API 分类规则表（数据模型）：`检查\RTOS检查\rtos_check.py`
│                               与 `rtosgen.cpp`（RTOS 骨架生成的生成前拦截）**共读同一份**
├── _stm32lookup.ini            速查页的收藏 / 最近 / 向导进度 / 上次板块（用户状态）
└── 说明.md                     本文件
```

> `rules\` 与 `data\` 分工：`data\` 是"查得到的资料"（条目），`rules\` 是"用来做判断的规则"
> （哪些 FreeRTOS 接口不适合在中断里调）。规则表里**不放芯片手册数据**——外设/引脚能不能用
> 一律从工程真值里扫，避免"凭印象写对照表"。改表即两边同时生效，不用重编。

## 一键重建整条链

```
工具箱\速查数据\tools\rebuild.bat          # 全链
工具箱\速查数据\tools\rebuild.bat /nodb    # 跳过打包 APK
```

链路每一环都不能少——**漏跑一环不会报错，只会静默用旧数据**（踩过两次），所以做成一条命令：

| 环 | 做什么 |
|---|---|
| 1/6 | 数据自检：`check_std_lib_data.py` + `check_quality.py`（在 `标准库速查\`） |
| 2/6 | 网页引擎回归：`_build_regress.js`（真跑网页引擎，验板块/渲染/排序） |
| 3/6 | 导出 `data\dataset.json`（`export_json.js`） |
| 4/6 | 重生成 `data\search_baseline.txt`（`export_json.js --baseline`，从现有基线读用例重跑回写） |
| 5/6 | 重编工具箱（`工具箱\构建.py`，含 qmake） |
| 6/6 | `Toolbox.exe --selftest`（含速查的计数与 28 例基线逐行回归，必须 0 失败） |
| 7/6 | 手机版单文件 + APK（`标准库速查手机版\构建APK.bat /auto`） |

> 别用 `findstr` 过滤中文输出（GBK 控制台匹配不上，会假报成功），靠退出码判断。
> `--baseline` 不许手打用例：**从现有基线文件读用例回写**，手打漏项只会"少比一行"而不报错。
> `rebuild.bat` 存为 **GBK + `chcp 936`**（不是 UTF-8）：cmd 读批处理按字节偏移定位，
> UTF-8 的中文（3 字节）会让指针错位、执行到错误位置（曾表现为 5/8 步报
> `'on' is not recognized as an internal or external command` 而整段中止）。
> 改这个文件请保持 GBK 编码。

## 桌面端命令行出口

入口在工具箱的 exe 上（速查自己的 CLI 已并进去）：

```
工具箱\程序\嵌入式工具箱\build\release\Toolbox.exe --selftest   # 全套自检（含速查回归）
工具箱\程序\嵌入式工具箱\build\release\Toolbox.exe --where      # 数据位置与条目统计
工具箱\程序\嵌入式工具箱\build\release\Toolbox.exe --search [--sec ref|guide|build] [词...]
工具箱\程序\嵌入式工具箱\build\release\Toolbox.exe --explain [--sec ...] 词   # 打分明细
工具箱\程序\嵌入式工具箱\build\release\Toolbox.exe --topics     # 主题归类逐条输出
```

## 与网页版、手机版的关系

- 网页版 `本地工具\标准库速查\`：唯一数据源，桌面端**只读不改**它的文件。
- 手机版 `本地工具\标准库速查手机版\`：另一条线——`build_mobile.py` 把网页 + 17 个数据文件
  内联成单文件 HTML，再同步进 Android 工程打 APK。改完网页数据必须重走这条链，
  否则手机上的还是旧包（有工具校验：`tools\check_sync.py`）。
- 页面功能（三个板块、搜索、收藏、向导进度等）见
  `工具箱\程序\嵌入式工具箱\说明.md` 的「STM32 速查」一节。
