## 本轮方向（2026-10-20 · 第二轮）—— 从「工程闭环」升级成「工程驾驶舱 · 平台化」

上一轮把工具箱从"只会报告"推到了"能动手"：阶段判定、生成阶段自检、编译烧录、时序仿真、代码索引。

这一轮**幅度大一些**：把这些**点连成面**（一条命令走完一个阶段、一屏看清项目脉搏），
并让工具箱自己长成**平台**（加检查器不用改 C++、加进来的东西自带验收）。一点一点把楼堆起来。

| 现在 | 这一轮要变成 |
|---|---|
| 判定阶段 / 生成自检 / 编译烧录 / 回写文档 各是一条命令，要你手工串 | **一条命令走完一个阶段**，出 PASS/FAIL 并归档 |
| 加检查器要改两处 C++（目前只有示例插件是插件） | **全部插件化 + 一键脚手架**，加检查器零改 C++ |
| 16 支脚本的 `--json` 各写各的键 | **一份 schema 契约**，谁改坏谁红 |
| 验证链靠你记一长串命令 | **一条命令分"快 / 全"两档**跑完，出结论 |
| 面板给"最该先看的 3 件事" | **驾驶舱**：项目脉搏 + 一键执行下一步 |
| 手册是手册 | 流程卡能一键变成**可编译的最小 demo 工程** |

**为什么现在敢这么做**（本轮现核的事实，不是拍脑袋）：
- 16 支脚本已有 `--json`（已核）；`boardcfg` 把板级常量抽成一份配置；阶段判据外置成 `stage_checks.json`；
- 插件机制（`检查\<名>\check.py --manifest`）已跑通（"示例插件"页就是它）；
- 本机 Keil（`E:\k5\UV4\UV4.exe`）、烧录器（`E:\stm32pro\bin\STM32_Programmer_CLI.exe`）、串口都在，
  工程 `CreateHexFile=1`、产物 `Objects\标准模板.hex` 现成。
