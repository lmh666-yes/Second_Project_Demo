# 进度与桩跟踪器

扫描仓库源码里的待办标记与疑似桩函数，生成 `进度报告.md`。
搭配自建阶段使用：骨架与桩写在源码里，本工具把它们汇总成一张清单。

## 用法

双击 `扫描进度.bat`，或命令行：

```
python 本地工具\工具箱\检查\进度跟踪\progress_scan.py
```

报告生成在本文件夹：`进度报告.md`（每次运行覆盖）。只读脚本，不改任何源码。

## 报告怎么看

1. 待办标记：源码注释与代码里的 TODO / FIXME / 待实现 等，带行号与原文。
2. 疑似桩函数（待实现）：空函数体，或函数体只有一句 return；且注释没说"有意留空"。
   带"含待办标记 = 是"的，基本就是要动手写的。
3. 疑似有意留空：例如 FWLIB 的 `EXT_*_Init`（默认态已满足需求，当前留空），核对后可忽略。
4. 进度文档现状：三份进度文档是否还空着。

## 可选参数

| 参数 | 作用 |
|---|---|
| `--root <路径>` | 指定扫描根，默认仓库根 |
| `--out <文件>` | 指定报告输出路径 |
| `--quiet` | 只在控制台打印摘要，不打印按文件清单 |

## 说明

- 跳过第三方与产物目录：FreeRTOS、ETH、RTE、qcustomplot、build 等。
- 桩函数是启发式判定，个别声明式写法可能误报，按清单核对即可。
- 两份 `main.c` 为 GBK 编码，脚本按 utf-8 / gbk 顺序自动解码。
