# 引脚与资源规划器

按模块看引脚与中断资源，并在选定一组模块后报出它们之间的冲突。
与 `仓库巡检/pin_audit.py` 的分工：pin_audit 只做全板体检，本工具用于"开工前选脚"。

## 用法

双击 `规划引脚.bat`，或命令行：

```
python 本地工具\工具箱\检查\引脚规划\pin_planner.py
python 本地工具\工具箱\检查\引脚规划\pin_planner.py --use "LORA_E22,W25QXX,RS485"
python 本地工具\工具箱\检查\引脚规划\pin_planner.py --board 2 --quiet
```

报告生成在本文件夹：`引脚规划报告.md`（每次运行覆盖）。只读脚本，不改任何源码。

## 报告内容

| 节 | 内容 |
|---|---|
| 总览 | 每板的头文件数、占用脚、冲突数、空闲数 |
| 方案检查 | 给出 `--use` 时，选中模块之间的冲突与引脚清单 |
| 模块与引脚 | 每个宏基名占用的引脚（基名、归并后的模块名、引脚、出处） |
| 冲突引脚 | 同一脚被 >= 2 个模块声明 |
| 无人认领引脚 | 库里没有任何模块声明的脚（选空闲脚先看这里） |
| 中断资源 | 可静态解析的 IRQn 与抢占/子优先级；抢占低于内核上限会标出 |

## 参数

| 参数 | 作用 |
|---|---|
| `--use <前缀,...>` | 指定一组模块基名前缀，只对它们做冲突预检 |
| `--board 1\|2` | 只处理某一块板 |
| `--out <文件>` | 指定报告输出路径 |
| `--quiet` | 只打印摘要 |

## 说明

- 引脚来自 `FWLIB\inc\*.h` 里成对的 `*_PORT` / `*_PIN` 宏，与 pin_audit.py 同口径。
- IRQn 由函数形参传入的写法（如按序号配置的 USART/TIM）无法静态解析，不列出。
- "无人认领"不等于硬件上一定空着，是"库里没有模块声明"。
