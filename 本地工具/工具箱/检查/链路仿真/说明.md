# 虚拟链路仿真器

硬件未到货时，造出与工程一致的字节流，喂给 Qt 上位机或协议工作台做联调。
协议口径与工程一致（20 字节环境帧、CRC16-MODBUS、0x15 历史帧、0x96 补传应答）。

## 用法

在工具箱窗口「检查 → 链路仿真」页点「运行」（默认 normal 场景），或命令行：

```
python 本地工具\工具箱\检查\链路仿真\link_sim.py --scenario normal --count 20
python 本地工具\工具箱\检查\链路仿真\link_sim.py --scenario replay
python 本地工具\工具箱\检查\链路仿真\link_sim.py --scenario lossy --count 30
python 本地工具\工具箱\检查\链路仿真\link_sim.py --selftest
```

生成两个文件：`<out>.hex`（连续十六进制）与 `<out>.log`（逐帧说明），
默认写到本目录下的 `产物\`（目录不存在会自动建）。

## 场景

| 场景 | 内容 |
|---|---|
| normal | 正常环境帧流，数值缓变 |
| lossy | 丢帧 + 帧间噪声，模拟无线不稳 |
| noise | 每帧前后夹随机噪声，测上位机重同步 |
| replay | 断网缓存补传：0x96 进行中 -> 若干 0x15 历史帧 -> 0x96 完成 |

## 怎么用这份字节流

1. 粘进协议工作台的解帧页：直接打开 `产物\link_normal.hex`，全选复制到解帧页即可。
   （若在综合程序里，跑完仿真后点「发送到协议工作台」可一键完成。）
2. 喂给 Qt 上位机：装一对虚拟串口（如 com0com），把一端给本工具、另一端给上位机：
   ```
   python link_sim.py --scenario normal --port COM6 --baud 115200
   ```
   需要 pyserial（`pip install pyserial`）。

## 参数

| 参数 | 作用 |
|---|---|
| `--scenario <名>` | normal / lossy / noise / replay，默认 normal |
| `--count <N>` | 帧数，默认 10 |
| `--seed <S>` | 随机种子，保证可复现 |
| `--out <前缀>` | 输出文件前缀，默认 `产物\link_<场景>` |
| `--port <COMx>` | 直接写串口（需 pyserial） |
| `--baud <N>` | 串口波特率，默认 115200 |

未知参数（含拼错的开关、缺值的选项）会**报错退出**并列出可用参数（退出码 2），
不会静默忽略——否则拼错一个开关就会按默认场景生成一堆产物。
