# 一键上传到 GitHub

## 用法（三种，任选）

1. **【推荐】把要上传的文件夹拖动到 `push_to_github.bat` 上松开** —— 自动检查、提交、推送；
2. 把 `push_to_github.ps1` + `push_to_github.bat` 复制进目标文件夹，双击 `.bat`；
3. 命令行：
   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File push_to_github.ps1 -Folder "D:\某文件夹" -Message "提交说明"
   ```

## 首次使用前提

- 已安装 git（https://git-scm.com/download/win），GitHub 账号登录过一次；
- 目标文件夹已绑定 GitHub 仓库：没绑定的话脚本会给出步骤，也可直接粘贴仓库地址自动绑定。

## 脚本会自动做的事

- `git init`（目标还不是仓库时，会先询问）→ `add` → `commit`（可输说明，回车用默认）→ `push`；
- 变更预览（新增/修改/删除计数）；大文件保护（>100MB 拦住）；推送失败自动重试一次；
- 本工具脚本自身不会被上传；本目录整体不入库。

> 提示：如果双击后提示"此文件夹还没有 git 仓库"，说明你是直接双击的——请改用"拖拽文件夹到 bat 上"。
