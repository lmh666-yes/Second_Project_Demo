# 大题内容改造规范（v1，严格执行）

## 背景与目标
文件 `D:\github\面试刷题\面试题刷题软件-大题\题库\03_编程画图大题.md` 中每道题的「**参考答案：**」段改造为两段：
- `**题目解析：**` —— 讲清原理 / 思路 / 推导 / 复杂度 / 易错点
- `**标准答案：**` —— 精简而完整的标准答案；**代码 / 程序设计题必须附完整代码**（题目要求写函数就给完整函数、要求写程序就给完整程序，能编译运行、带简短注释）
「**得分点：**」段保持原样一字不动；题干、其它题一律不动。

## 硬性格式
改造后每题结构：
```
**N.** 题干……（原样保留）

**题目解析：** <单行长段落>
**标准答案：** <正文；代码必须放在 ``` 围栏里>
**得分点：** <原文，不动>
```
- 替换范围：从 `**参考答案：**` 行开始，直到 `**得分点：**` 行之前（含原答案的所有行）。
- 标准答案中的代码必须使用 ```c / ```cpp / ```verilog 等围栏块（原文代码已有围栏的保留围栏与语言标注）。
- 代码外正文不得出现行首 `#`、`---`、`**` 序列；C 的二级指针写作 `int * *p`（解析器会剔除连续 `**`，务必避免）。
- 「题目解析」写成单行长段落；「标准答案」可多行（含代码块）。

## 内容质量标准（关键！）
1. **完整准确**：原文全部技术信息必须保留；不得改变结论、数字、代码逻辑、术语；不得编造。原文笔误可纠正（并在解析中说明），但不得引入新主张。
2. **标准答案** = 考试可提交的答案：
   - 编程题：**完整代码**——完整函数/结构体定义 + 必要注释；原文只有片段时补全为完整可运行函数/程序（题目说“程序”就给含 main 的完整程序；说“函数”就给完整函数并附一句调用示例）。代码后给 1~3 句关键说明（复杂度/边界）。
   - 判定/说明题：直接给结论与依据（1~6 句）。
   - 画图/波形/时序题：图面要点 + 参考文字描述（完整、可照着画）。
3. **题目解析** = 展开讲解：原理、推导步骤、复杂度分析、边界与易错点、延伸考点；行文通顺，不要重复代码本身。
4. 风格：专业、紧凑、直给结论；可用 `` `反引号` `` 标注、①②③ 分点。

   ```python

   NEW = {
       6: ("……题目解析（单行）……", "……标准答案（可多行，用 \n 连接，含代码围栏）……"),
       # ……
   }
   ```
   - 多行标准答案示例：`"完整程序如下：\n```c\n#include <stdio.h>\nint main(void){return 0;}\n```\n要点：……"`（注意 \n 是真实转义）。
   - 字符串用英文双引号包裹；内部英文引号 `\"` 转义。
3. 运行：`python D:\github\面试刷题\工具\题库批处理\apply_big_batch.py D:\github\面试刷题\工具\题库批处理\batch_big_X_data.py` —— 必须输出「成功改造 N 题」，有失败修正后重跑（失败不会写坏文件）。
