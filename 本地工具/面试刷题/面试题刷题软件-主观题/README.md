# 面试题刷题软件 · 主观题

> **版本：2.11.1**（2026-10-13）
> 题库：**面试题库 · 主观题** —— 填空 / 简答 / 计算 / 写结果 / 文字代码分析，共 **490 题**（已全库查重去重）
> （来源：2022~2026 全部面试试卷 + `附加面试题`（面试题4 / 面试题5 / 面试题6 / 面试题7 / 笔试题1 / 笔试题3 / 欣诺通信 / 附加面试题2.0 的面试题1・面试题2・面试题3・面试题4）整理；**2026-10-05 全量重构：每题「📖 题目解析 + ✅ 标准答案 + 📝 自评要点」**；`题库/02_主观题.md`）
> **只有纯文字题与「文字 + 代码分析」题**（求结果、找错、改错、评论代码、概念简答）。
> 需要**写代码**或**看图 / 画图**的题已全部收在 **`03_编程画图大题.md`**（33 题迁出 + 73 题大题汇编 + 15 题附加面试题 + 10 题面试题5/6/7 + 10 题查漏补缺补充题 + 11 题函数专项 + 4 题附加面试题2.0·面试题3 编程篇 + 1 题面试题4 编程题 = **170 题**，编号 401~544）。

**打字作答、不判对错**：每题输入框打字自测 → 「查看参考答案」对照 **题目解析 + 标准答案 + 自评要点**。
含**模拟考试（10 题 / 40 分钟）**：交卷后逐题回顾对照答案自评；无错题库。

## 快速开始

1. 双击 **`启动刷题软件.bat`**（自动定位 Python；若缺 `题库.json` 会自动从 `题库/` 生成）
2. 或命令行：`python core/build_bank.py` 生成题库 → `python core/主观题软件.py` 打开

## 功能

| 功能 | 说明 |
|---|---|
| **顺序浏览** | 上一题 / 下一题，覆盖全部 490 题 |
| **🔥 热点（v2.9 新）** | 按全网高频（leetcode / dotcpp / 嵌入式招聘要求）划出的前 50% 高频题单独成板块：**238/490**；统计栏显示 🔥热点 n |
| **🧠 进度记忆** | 打开软件自动跳到「**连续完成题目的最后一题**」：做了 1、2、3、4，跳过 5 又做了 6、7、8，下次打开就在**第 4 题**（题头显示「↩ 已回到上次进度」）；切到考试再回来则回到刚才浏览的位置 |
| **🔁 记忆模式（v3.1 新）** | 主动回忆 + 间隔重复：点「💡 提示」先看题目解析与自评要点首字线索，再点「👀 查看参考答案」对答案；看完用 **😖 忘了 / 🤔 模糊 / 😎 记住**（快捷键 1/2/3）自评，系统按 **1 / 1 / 3 / 7 / 15 / 30 天**安排下次复习；新增「🔁 复习」板块只剩到期题；顶栏第二行显示 待复习 / 已掌握 / 学习中 / 今日自评 |
| **✍️ 打字作答** | 每题输入框，**自动保存**；切题、关闭程序均不丢失 |
| **👀 查看参考答案** | 一键显示 **📖 题目解析 → ✅ 标准答案 → 📝 自评要点**（分色），再点「收起」隐藏 |
| **跳题（已修复）** | 顶栏「跳题号」输入回车：**先按题号精确跳**；题号不存在时**兑底按“第 n 题”（顺序位置）跳**；都不行时提示真实题号范围（1~532，含空档说明） |
| **⭐ 收藏** | 题目页点「⭐ 收藏」加入收藏；**取消收藏只能在「收藏」板块点「💔 取消收藏」**（带确认弹窗）；顶部统计显示收藏数；重置进度时**收藏保留** |
| **📂 分区跳转** | 顶栏「📂 分区」打开目录：左侧按年份/大类分组的**分区树**（区块=试卷名，如“2021面试题-3”），右侧该分区**题目清单**（题号+摘要）；点题目→**弹窗确认**→自动切到顺序板块并定位；双击题目也可直接跳；**窗口为可拖动分栏（4:6）+ 双滚动条 + 最小尺寸 860×560**（v2.9 挤压修复） |
| **统计** | 顶部实时显示 **已看答案 x/490 · 已作答 y/490 · ⭐收藏 n · 🔥热点 238** |
| **🎓 模拟考试** | 每次 **10 题 / 40 分钟**；**环形抽题：同一场绝不重复，连续多场必覆盖全部 490 题**（每题间隔 ≤40 场）；暂停/退出/恢复；**交卷后逐题回顾**（我的作答 + 题目解析 + 标准答案 + 自评要点）自评 |
| **长内容不丢** | 超长题干/参考答案自动增高，超限出现滚动条；窗口按屏幕自适应并居中；高分屏 DPI 感知；◀/▶ 翻题快捷键；**超长题干（>6000 字）快速路径，秒开不卡顿** |
| **🗑 重置进度** | 连续 3 次确认 + 最后 5 秒冷静期 |
| **不打分** | 无对错、无错题库 |

## 题库更新 / 切换

1. 把 **02 风格 md 题库**（每题带「**参考答案：**」与「**得分点：**」行）放进 **`题库/`** 文件夹（可放多个用于切换）
2. 双击 **`更新题库.bat`** → 选择文档 → 自动解析并覆盖 `题库.json`
3. 重新打开刷题软件即可

> 题库文件夹里现在有两份：`02_主观题.md`（490 题，默认）与 `03_编程画图大题.md`（170 题）。
> 想专门练**编程 / 画图大题**时，用「更新题库」选择 `03_编程画图大题.md` 即可把它导入软件（作答方式一样：打字 → 对照参考答案）。
