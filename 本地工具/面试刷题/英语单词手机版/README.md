# 英语单词刷词软件（手机版）· 计算机专业英语词汇

> 词库：**计算机专业英语词汇终结版.pdf**（2022 版），自动提取 **734 个单词/缩写**（英文 + 中文释义）。
> 纯手机端：**单文件网页**（浏览器直接打开）+ **APK 安装包**；离线可用、进度存在手机本地。
> 三种模式：**顺序 / 错词 / 考试**；选择题选项每次随机（1 个正确 + 3 个随机），考试为**填空听写**。
> **错词寿命机制**：答错即入错词本（寿命初始 1）；累计错误达 **3、5、7、9** 次各 +1，**超过 10 次后每错一次 +1**；只有**「错词考试」答对**才寿命 -1，归零后移除。

## 一、功能

| 模块 | 形式 | 说明 |
|---|---|---|
| **顺序** | 选择题 | 显示英文单词 → 4 个中文选项（**1 个正确答案 + 3 个随机干扰**，选项顺序随机；干扰项自动排除**与答案同义或互为子串**的释义，避免出现两个"都对"的选项）；答对自动进入下一个单词，答错**立刻显示正确答案**并加入错词本 |
| **错词** | 选择题 | 只练答错过的词；**在错词板块答对不再移除**（需到「错词考试」里答对才会减寿命）；每题累计错误次数永久记录、显示错词寿命 |
| **📝 错词考试** | 选择题 | 错词板块内按钮进入：从错词本**随机抽 ≤10 个词**（给英文选中文、选项随机），规则同考试（可暂停/交卷/逐题回顾/错词号回顾）；**答对寿命 -1、归零后移出错词本**；答错寿命不变（累计错误达阈值仍会 +1） |
| **考试** | 填空听写 | **随机抽 20 个单词**，给英文、你输入中文意思 → 点「确认答案」**立刻对照**；每题 5 分，满分 100；答错自动进错词本 |
| **进度记忆** | — | 打开自动跳到「**连续完成题目的最后一个单词**」：做了 1、2、3、4，跳过 5 又做了 6、7、8 → 下次打开就在**第 4 个** |
| **统计** | — | 顶部显示 **已做 x/734 · 正确率 n% · 错词 m** |
| **考试控制** | — | 暂停 / 继续 / 随时交卷；考试中断电或关页面**自动保存**，下次打开继续；交卷后**成绩页 + 逐题回顾**（含错题号一键回顾） |
| **重置** | — | 连续 3 次确认后清空全部记录 |

### 考试答案怎么判对？

| 规则 | 例子 |
|---|---|
| 去空格、忽略大小写无关的中英标点、忽略句末句号 | 输入「 绝对 。」= 绝对 ✓ |
| **省略号等价**：`…` = `...` = `什么` = `XX` | 标准答案「改变…的位置」，输入「改变…的位置」「改变什么的位置」「改变...的位置」「改变XX的位置」**都算对** |
| 释义含多个义项（以 `，` `；` `/` 分隔）时，**答出任一义项即算对** | 标准答案「陪同，伴随」，输入「陪同」✓ 或「伴随」✓ |
| 其它情况必须一致 | 「保存」≠「绝对」✗ |

> 想改成"必须一字不差写完整释义"也很简单：编辑 `www/template.html` 里的 `checkMeaning()`，删掉按义项切分的循环即可（改完重新运行 `build_web.py` / `构建APK.bat`）。

## 二、三种使用方式

### 方式一：手机浏览器直接打开（免安装）

把根目录的 **`英语单词刷词.html`** 发到手机（微信/QQ/数据线都可以），用**浏览器**打开：

- **Android**：文件管理器点该文件 → 「用浏览器打开」（别用不执行脚本的"HTML 查看器"）
- **iOS**：存到「文件」→ 长按 → 共享 → 用 Safari 打开
- 在微信/QQ 里直接点开通常不能运行：点右上角「…」→「用其他应用打开」→ 选浏览器
- 进度存在浏览器本地（localStorage）：**换浏览器或清理数据会丢**，重要记录请别清缓存

### 方式二：安装 APK（推荐）

| 文件 | 位置 | 大小 |
|---|---|---|
| **`英语单词刷词.apk`** | 本文件夹根目录 | 约 3 MB |
| `app-release.apk` / `app-debug.apk` | `android\app\build\outputs\apk\…` | 同上 |

安装：把 APK 发到手机 → 点击 → 允许「安装未知来源应用」→ 桌面出现「**英语刷词**」图标（需 Android 7.0 及以上）。

> **不会和别的 App 冲突**：本应用包名是独立的 `com.cquiz.enword`，并使用**专属签名密钥** `android\enword-release.jks`
> （与「面试刷题·客观」`com.cquiz.app`、「面试刷题·主观」`com.cquiz.subj` 完全不同）——三个应用可以同时安装，
> 以后升级本应用也只需覆盖安装即可（**请保留 `enword-release.jks` 和 `keystore.properties`**，换签名会导致无法覆盖升级）。

### 方式三：Android Studio 自行打包（可选）

用 Android Studio 打开本文件夹下的 **`android`** 子目录 → 等待 Gradle Sync → `Build → Build APK(s)` → 产物在 `android\app\build\outputs\apk\debug\app-debug.apk`。

## 三、词库：来源、重新提取、增删改

- 提取脚本：`tools/extract_pdf.py`（读取仓库根目录的 `计算机专业英语词汇终结版.pdf`）
  ```bat
  python tools\extract_pdf.py
  ```
  它会生成 `词库\词库.csv` 与 `词库.json`（两者内容一致，CSV 方便用 Excel 打开）
- 想**手工增删单词**：直接编辑 `词库\词库.csv`（三列：英文, 全称/缩写, 中文释义），删掉 `词库.json` 后运行 `build_web.py` 会自动从 CSV 重建
- 想**换整本词库**：把新的 PDF 放仓库根目录，改 `tools/extract_pdf.py` 里的文件名后重新运行
- 提取规则（PDF 里的排版约定）：
  - 一行 = 「英文 + 中文」，中文从第一个汉字开始
  - 纯中文行 / 数字开头的行 = 上一条释义的换行续行（自动拼回）
  - "其他缩写"段：`缩写 全称 中文` → 单词取缩写，全称单独显示
  - `Domain name system（DNS）` → 单词 `Domain name system`，括号里的 `DNS` 作为全称显示
  - 同名单词重复出现 → 释义合并（用 `；` 连接）

## 四、重新生成网页 / 重新打包 APK

```bat
python build_web.py        :: 词库.json + www\template.html → www\index.html / 英语单词刷词.html / android assets
构建APK.bat                 :: 一键：生成网页 → Gradle 构建 → 复制 APK 到根目录
```

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 打开 html 显示「⚠️ 脚本错误 / 初始化失败」 | 说明浏览器太旧或数据损坏；应用会自动清理本地数据，刷新即可。建议用 Chrome / Edge / 夸克等现代浏览器 |
| 微信里点开没反应 | 「…」→ 用其他应用打开 → 浏览器 |
| 手机上字体太小/按钮点不到 | 页面按手机宽度自适应（最大 520px），横屏或浏览器缩放均可 |
| 换手机后进度没了 | 进度只存在本机浏览器/应用内，不会上传云端 |
| APK 装不上 / 提示签名冲突 | 本应用包名与签名都是独立的；若曾装过"修改过包名"的同名应用，请先卸载旧版再装 |
| 想清空全部记录 | 底部「🗑 重置」→ 连续 3 次确认 |
