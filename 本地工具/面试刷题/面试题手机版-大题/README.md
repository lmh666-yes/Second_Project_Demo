# 面试刷题 · 大题（手机版）

> 基于桌面版「面试题刷题软件-大题」制作的**手机端应用**。内置题库：**面试题库 · 编程 / 画图大题**（写代码 + 看图 / 画图题，共 **170 题**，每题「📖 题目解析 + ✅ 标准答案 + 📝 自评要点」已逐题重构；🔥 热点板块 83 题）。
> 打字作答、对照参考答案（参考实现 / 图面要点）+ 得分点；**不打分、无错题库**；含**模拟考试（10 题 / 40 分钟）**；**⭐ 收藏题目 + 📂 分区跳转**；配图（电路/波形/时序图 26 张）base64 内嵌，离线可看；**🔁 记忆模式（提示 → 对答案 → 自评，间隔重复复习）**。单文件、离线可用。
> **📦 APK 安装包已构建好**：根目录 **`面试刷题-大题.apk`**（直接发到手机安装，见「方式二」）。

## 三种使用方式

### 方式一：手机浏览器直接使用（免安装）

**推荐发送根目录的 `面试刷题-大题.html`**（与 `www/index.html` 内容相同，名字更直观）。

**手机上打开的正确姿势（重要）：**

- **Android**：文件管理器点击该文件 → 选择「用浏览器打开」（不要用不执行脚本的「HTML 查看器」）。
- **微信/QQ 里直接点开 .html 通常无法运行**：请「用其他应用打开 → 浏览器」，或先保存到手机再打开。
- **iOS**：存到「文件」App → 长按 → 共享 → 在 Safari 中打开。
- 若看到「⚠️ 题库未加载」提示 → 打开的是模板 `template.html`，请改开 `index.html` / `面试刷题-大题.html`。

无需安装、无需联网，作答与看答案记录自动保存在手机本地（localStorage）。

### 方式二：直接安装 APK（推荐 · 已构建好）

本机已完成命令行构建，**无需 Android Studio**：

| 文件 | 位置 | 大小 |
|---|---|---|
| **`面试刷题-大题.apk`** | 本文件夹根目录 | 约 6.1 MB |
| `app-debug.apk`（同一版本） | `android\app\build\outputs\apk\debug\` | 同上 |

**安装步骤**：把 `面试刷题-大题.apk` 发到手机 → 手机上点击该文件 → 按提示**允许“安装未知来源应用”** → 桌面出现「面试刷题·大题」图标，点击即可使用（需 Android 7.0 及以上）。

> **三个刷题 App 互不冲突**：本应用包名为 `com.cquiz.bigq`（版本 1.2），客观题版 `com.cquiz.app`（1.2）、主观题版 `com.cquiz.subj`（1.4）——**三个 APK 可以同时安装在同一台手机**，互不覆盖。

**以后题库更新后如何重新构建（本机环境已配好）**：双击 **`构建APK.bat`** 即可（自动：重新生成内嵌题库 → Gradle 构建 → 复制 APK 到根目录）。

### 方式三：从源码自行打包 APK（Android Studio，可选）

把本文件夹放到另一台电脑（装有 Android Studio）上构建 APK：

1. 打开 Android Studio → `Open` → 选择本文件夹下的 **`android`** 子文件夹（不是整个文件夹，也不是 `www`）
2. 等待 Gradle Sync 完成（首次需联网下载依赖，约 5–15 分钟；SDK 缺 API 35 时按提示点下载）
3. 菜单 **`Build → Assemble Project`**（或 `Build → Build Bundle(s) / APK(s) → Build APK(s)`）
4. 左下角出现 **`BUILD SUCCESSFUL`** 后，APK 位于：`android\app\build\outputs\apk\debug\app-debug.apk`
5. 把 **`app-debug.apk`** 发到手机安装（需允许“安装未知来源应用”）

> 系统要求：Android 7.0（API 24）及以上。详细排障可参考「面试题手机版-客观题」README 中的常见问题表。

## 功能

- **顺序练习**：上一题 / 下一题，覆盖全部 170 题
- **🔥 热点（新）**：按全网高频划出的前 50% 高频题（**83/170**）单独成板块；顶部统计显示 🔥热点数
- **🖼 大题配图**：电路 / 波形 / 时序图直接显示；**点图片可全屏查看**——单指拖动平移、双指捏合缩放、双击放大/还原
- **🧠 进度记忆**：打开自动跳到「**连续完成题目的最后一题**」（「已作答」或「已看过参考答案」都算完成）；切到考试再回来则回到刚才浏览的位置
- **✍️ 打字作答**：每题一块输入框，**自动保存**（本机 localStorage），切题、关闭不丢失
- **👀 查看参考答案**：一键显示 **📖 题目解析 → ✅ 标准答案 → 📝 自评要点**（紫/绿分色，代码题附完整代码），再点收起
- **✅ 答案优先 + 代码块（新）**：查看答案时先显示 **`✅ 标准答案`**，再显示 `📖 题目解析`，最后 `📝 自评要点`；答案/解析里的代码自动渲染成深底等宽代码块。
- **🔁 记忆模式（新）**：💡 提示（先只看题目解析 + 自评要点首字线索）→ 👀 查看参考答案 → 😖 忘了 / 🤔 模糊 / 😎 记住 自评；按**间隔重复**（1/1/3/7/15/30 天）安排下次复习
- **🧠 复习板块（新）**：顶部「🧠 复习」自动列出到期该复习的题；没有到期题时可一键「提前复习最不熟的 10 道」；复习中点「忘了」会排到队尾再来一遍
- **⭐ 收藏题目**：底部「⭐ 收藏」一键收藏（收藏后在「⭐ 收藏」板块查看）；**取消收藏只能在「⭐ 收藏」板块点「💔 取消收藏」，且弹窗确认后才生效**；顶部实时显示收藏数
- **📂 分区跳转**：顶部「📂 分区跳转」→ 按来源分组（6 大区 30 分区）→ 点开分区看该区题目清单 → 点题目**弹窗确认后才跳转**
- **🎓 模拟考试**：每次 **10 题 / 40 分钟**，**环形抽题（同一场绝不重复，连续 17 场必覆盖全部 170 题）**；暂停 / 退出 / 恢复；交卷后成绩页 + 逐题回顾对照答案自评（不打分）
- **统计**：顶部实时显示 **已看答案 x/170 · 已作答 y/170 · ⭐收藏 n · 🔥热点 83**；第二行显示 **🧠 记忆模式 · 待复习 d · 已掌握 m · 学习中 k · 今日自评 t**
- **🗑 重置进度（3 次确认）**
- **不打分、无错题库**：纯“自测 → 对照”模式
- 现代 UI：渐变背景、圆角卡片、作答框聚焦高亮、答案滑入动画

## 重新生成（题库更新后）

若桌面版 `面试题刷题软件-大题/题库.json` 更新了，重新生成手机版：

```bash
python build_web.py
```

会同时更新：
- `www/index.html`（浏览器版）
- 根目录 `面试刷题-大题.html`（友好名）
- `android/app/src/main/assets/index.html`（APK 版）

> 配图在生成时自动做**手机端自适应**（最大宽度 1000、灰度 PNG），本库配图 7.4 MB → 2.6 MB，内嵌页面 10.3 MB → 4.1 MB（APK 从 10.5 MB 降到 6.1 MB）；桌面版仍使用 `imgs/` 原图。
> 重建 APK 用 **`构建APK.bat`** 即可（2026-10-13 起脚本已内置 `clean`；此前需手动 clean（本次实测：增量构建会产出 9.1 MB 的虚高包，clean 后为 6.1 MB）（增量构建会在 APK 里留下旧版页面的空洞，体积虚高）；最近一次已 clean 重建并验证（6.1 MB，含 170 题 / 热点 83 与三段答案）。
> 重新生成后，再用 **`构建APK.bat`**（或 Android Studio）重新 Build APK 即可。

## 文件结构

```
面试题手机版-大题/
├── build_web.py             从桌面版题库生成手机版 index.html（含配图压缩）
├── www/                     浏览器版（单文件离线应用）
│   ├── template.html        模板（含功能代码，题库为占位符）
│   └── index.html           最终生成版（题库内嵌，直接可用）
├── 面试刷题-大题.html        根目录友好名（与 index.html 相同）
├── 面试刷题-大题.apk         安卓安装包（独立包名 com.cquiz.bigq + 独立图标）
└── android/                 Android 工程（Android Studio 打开构建 APK）
    └── app/src/main/
        ├── AndroidManifest.xml
        ├── java/com/cquiz/app/MainActivity.java   WebView 壳
        ├── res/values/styles.xml
        └── assets/index.html                      内嵌题库的应用
```

## 说明

- 纯 HTML/CSS/JS 单文件实现，无任何外部依赖，离线可用
- WebView 已启用 JavaScript 与 localStorage（作答持久化）
- 应用图标/名称可在 Android Studio 中按需修改
