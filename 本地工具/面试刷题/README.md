## 六套软件怎么用

| 端 | 入口 | 说明 |
|---|---|---|
| 桌面 | 各软件目录下 `启动刷题软件.bat` | 客观：自动判分 / 错题寿命 / 错题考试；主观·大题：打字作答 + 三段答案（题目解析 / 标准答案 / 自评要点） |
| 手机 | `面试刷题-*.apk`（发到手机安装）或 `面试刷题-*.html`（浏览器直开） | 题库快照内嵌，**离线可用** |

## 常用构建 / 维护命令

```powershell
# 重建题库（改题后）
python 面试题刷题软件-主观题\core\build_bank.py      # → 题库.json（454 题）
python 面试题刷题软件-大题\core\build_bank.py        # → 题库.json（156 题）

# 重建手机版网页（题库快照内嵌；三个手机版同理）
cd 面试题手机版-主观题; python build_web.py

# 一键 clean 重建三端 APK（防增量构建空洞）
工具\build_all_apks.bat
python 工具\check_apk.py                             # 抽查 APK 内嵌题量/热点

# 跑测试（进各软件 tests 目录；run_tests.py 需带测试文件名）
python run_tests.py smoke_subjective.py test_fav_section.py
```

## 工具/（构建工具）

| 位置 | 用途 |
|---|---|
| `工具/build_all_apks.bat` | 三端 APK 一键 clean 重建（脚本相对定位） |
| `工具/check_apk.py` | 抽查三个 APK 内嵌页面：题量 / 热点 / 三段答案 |
| `工具/素材识别/` | 素材识别.py + ocr_win.ps1：扫描图 / PDF / docx → 文字，生成 `_识别结果.md` |
| `工具/题库批处理/` | 题库内容改造与批次追加全套脚本（改造规范、apply / insert / verify / hot_pick…），详见 `工具/README.md` |
