# 仓库巡检工具

检查本仓库（自动定位仓库根，见下）的：内容齐全性 / 架构吻合度 / 编译记录 / git 状态 / 仓库卫生。

## 用法

双击 `project_check.bat`（或命令行运行 `project_check.ps1`）。

- 脚本会自动从本目录**向上逐级查找仓库根**（含 `EnvMonitor` 或 `.git` 的文件夹），找到后按它检查；
- 报告生成在**本文件夹**：`检查报告.md`（每次运行覆盖）。

## 以后要改什么

- 关键文件清单、驱动模块清单：都在脚本开头对应区段，照格式增删；
- 编译记录：读各工程的 `build_verify.log`，无需配置。

> 本目录属于"本地工具"，不入库（`.gitignore` 已忽略 `本地工具/`）。
