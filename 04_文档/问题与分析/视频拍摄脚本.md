# 项目演示视频 · 拍摄脚本与整理清单

> 用途：简历附链接 / 面试发送 / 作品集
> 目标时长：**4~5 分钟**（超过 6 分钟面试官不会看完）

---

## 一、拍摄前：先把“乱”分成三类

| 类别 | 具体问题 | 处理方式 |
|---|---|---|
| **台面乱** | 杜邦线像蜘蛛网、模块东倒西歪 | 见第二节，30~60 分钟能搞定 |
| **界面乱** | 串口助手刷屏、桌面图标多 | 只留必要窗口，全屏，深色主题 |
| **节奏乱** | 现场临时找代码、找按钮 | 提前彩排 2 遍，写好操作顺序 |

## 二、物理整理（优先级从高到低）

### 1. 供电先理清（最重要）
- 板2 用 **DC 5V 独立供电**，板1 可用 USB
- **大电流器件单独走线**：LoRa、ESP8266 的电源线不要和传感器共用一根细线
- 每个模块电源脚就近并 **0.1µF**，总线加 **100µF**

### 2. 线束收拢
- 用**扎带**把同方向的线捆成一束，不要交叉
- 线长宁短勿长，多余的线盘起来扎住
- **颜色规范**：红 = 电源，黑 = 地，黄/绿 = 信号
- 没有彩色线就用**标签纸**写：`3V3`、`GND`、`TX`、`RX`

### 3. 模块固定
- 双面胶 / 电工胶带 / 亚克力板 / 洞洞板，**别让模块悬空**
- 屏幕、板子、模块按“检测端在左、网关在右”摆
- **LoRa 天线朝上**，远离金属和人体

### 4. 布景
- 桌面铺深色布或一张白纸当背景
- 光源在**侧前方**（台灯），别用顶灯直射（会反光）
- 手机/相机用三脚架或支架固定，**俯拍 45°**

## 三、分镜脚本（4~5 分钟）

| 时间 | 画面 | 内容要点 | 注意事项 |
|---|---|---|---|
| 0:00–0:15 | 全景：两块板 + 屏 + 电脑同框 | 一句话介绍：“这是一个双板环境监测系统，检测端采集，网关端上云” | 屏幕要先点亮 |

## 五、拍摄前检查表

- [ ] 两块板都上电，屏幕正常显示
- [ ] Qt 能连上 COM 口，曲线在动
- [ ] 手机热点已开，板2 显示 `Net: ONLINE`
- [ ] 串口助手已关闭（避免占用 COM）
- [ ] 桌面清空，只留设备
- [ ] 手机支架/三脚架就位

## 六、常见翻车点

| 风险 | 预防 |
|---|---|
| 拍到一半屏幕黑了 | 提前确认 LCD 上电复位（断电重上再开拍） |
| 数据不动 | 板1 的 I2C 若卡死，先断电重启再拍 |
| Qt 打不开串口 | 关掉串口助手 |
| 断网演示失败 | 先手动试一次，确认 `cache` 会涨 |
| 视频太长 | 每段拍完立刻停，后期剪，不要一镜到底 |
| 声音听不清 | 用手机外接麦，或在安静房间录旁白后期配 |
