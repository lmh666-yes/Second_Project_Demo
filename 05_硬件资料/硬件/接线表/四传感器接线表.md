# 板1 四路传感器接线表（面包板版）

> 适用：STM32F407（板1）· I2C1 · PB8=SCL / PB9=SDA
> 原则：I2C 是总线，四路挂在同一条 SCL/SDA 上，靠地址区分

---

## 一、板子这一侧（源头）

| 板1 引脚 | 作用 | 线色建议 |
|---|---|---|
| **PB8**（P3 第 1 针） | SCL | 黄 |
| **PB9**（P3 第 2 针） | SDA | 绿 |
| **3.3V**（P3 第 3 针） | 电源正 | 红 |
| **GND**（P3 第 4 针） | 电源负 | 黑 |

⚠️ 千万不要接 5V，四个传感器全是 3.3V。

---

## 二、四个传感器的引脚定义

### ① SHT30（温湿度）· 4 针

| 引脚 | 定义 | 接到 |
|---|---|---|
| 1 | VCC | 3.3V |
| 2 | GND | GND |
| **3** | **SDA** | SDA 母线 |
| **4** | **SCL** | SCL 母线 |

⚠️ **SHT30 的 3、4 脚和下面两个是反的**，一定看模块丝印。

---

### ② BMP280（气压）· 4 针

| 引脚 | 定义 | 接到 |
|---|---|---|
| 1 | VCC | 3.3V |
| 2 | GND | GND |
| 3 | SCL | SCL 母线 |
| 4 | SDA | SDA 母线 |

地址：**0x76**（SDO 接高则 0x77）

---

### ③ BH1750（光照）· 4 针

| 引脚 | 定义 | 接到 |
|---|---|---|
| 1 | VCC | 3.3V |
| 2 | GND | GND |
| 3 | SCL | SCL 母线 |
| 4 | SDA | SDA 母线 |

地址：**0x23**（ADDR 接高则 0x5C）

---

### ④ CCS811（空气质量）· 8 针 ← 最麻烦

| 引脚 | 定义 | 接到 | 说明 |
|---|---|---|---|
| 1 | VCC | 3.3V | |
| 2 | GND | GND | |
| 3 | SCL | SCL 母线 | |
| 4 | SDA | SDA 母线 | |
| **5** | **nWAKE** | **GND** | ⚠️ 必须接地，否则扫不到 |
| 6 | nINT | **悬空** | 不用 |
| **7** | **nRESET** | **3.3V** | ⚠️ 接地会一直复位 |
| **8** | **ADDR** | **GND** | ⚠️ 接地=0x5A，接 3.3V=0x5B |

**这三根线（5、7、8）接错任何一根，CCS811 都不会出现在扫描列表里。**

## 三、总接法（一张表看完）

| 传感器 | VCC | GND | SCL | SDA | 其它 |
|---|---|---|---|---|---|
| SHT30 | 1 | 2 | **4** | **3** | — |
| BMP280 | 1 | 2 | 3 | 4 | — |
| BH1750 | 1 | 2 | 3 | 4 | — |
| CCS811 | 1 | 2 | 3 | 4 | 5→GND、7→3V3、8→GND |

## 四、面包板怎么摆

```
   上排电源轨（VCC 红）  ●──●──●──●──●──●──●
   ─────────────────────────────────────────
        [SHT30]   [BMP280]  [BH1750]  [CCS811]
   ─────────────────────────────────────────
   下排电源轨（GND 黑）  ●──●──●──●──●──●──●

   中间两行当母线：
   行A： ●──●──●──●──●  ← SCL（黄）
   行B： （空一行，隔开）
   行C： ●──●──●──●──●  ← SDA（绿）
```

**走线规则：**
1. 每个传感器 VCC → 上排电源轨（短跳线）
2. 每个传感器 GND → 下排电源轨（短跳线）
3. 每个传感器 SCL → 行 A（短跳线）
4. 每个传感器 SDA → 行 C（短跳线）
5. 板子的 PB8 → 行 A 最左端
6. 板子的 PB9 → 行 C 最左端
7. 板子的 3.3V → 上排电源轨，GND → 下排电源轨

## 五、上电验证顺序（一个一个加）

**每次加模块前，先断电。**

### 第 1 步：只接 SHT30

```
[I2C] scan 1 dev : 0x44
SHT30 init=0 proto=1
```
- 没扫到 0x44 → 检查 3/4 脚是不是插反了

### 第 2 步：加 BMP280

```
[I2C] scan 2 dev : 0x44 0x76
BMP280 ID=0x58
```

### 第 3 步：加 BH1750

```
[I2C] scan 3 dev : 0x23 0x44 0x76
BH1750 Lux=35.2
```

### 第 4 步：加 CCS811

```
[I2C] scan 4 dev : 0x23 0x44 0x5A 0x76
CCS811 HWID=0x81
```

**四个地址都出现 = 总线接对了。**

## 六、常见错误对照表

| 现象 | 原因 | 处理 |
|---|---|---|
| 扫描 0 个器件 | SCL/SDA 接反或没通 | 对调试试 |
| 扫描只有自己（比如 0x1A/0x50/0x68） | 这几个是板上固有的，不代表传感器 | 看有没有 0x44/0x76/0x23/0x5A |
| 某个地址时有时无 | 面包板接触不良 | 重新插、换孔 |
| CCS811 完全没有 | 5/7/8 脚接错 | 按上表重新接 |
| 全部器件时好时坏 | 供电不足或没去耦 | 加 0.1µF、换短粗线 |
| 读到 0x44 但读数报 **-4** | 数据段 NACK | 模块是 SHT4x，代码已自动识别；若仍失败查线长 |
| 上电后 I2C 卡死 | 从机被拉死总线 | 断电 10 秒再上电 |

---

## 七、去耦电容

每个模块旁边（面包板相邻行）插一颗 **0.1µF 瓷片电容**，一脚 VCC 一脚 GND。

没有电容也能跑，但会出现“偶尔抽风”，尤其是 CCS811 加热时。

---

## 八、断电检查清单

上电前最后确认：

- [ ] 四路的 VCC 都接 **3.3V**，没有 5V
- [ ] 四路的 GND 都接 GND（共地）
- [ ] SCL 全部接到同一行，SDA 全部接到同一行
- [ ] SHT30 的 3/4 脚没有和别的一起插反
- [ ] CCS811 的 5=GND、7=3V3、8=GND
- [ ] 面包板电源轨中间是通的（万用表量两端）
- [ ] 没有裸线头互相碰到
