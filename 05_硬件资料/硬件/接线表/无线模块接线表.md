# 无线模块接线表（LoRa E22 + ESP8266 ESP-01S）

> 两个无线模块都在**串口**上，接法大同小异：都是"交叉接 + 供电 + 模式脚拉低"

---

## 一、LoRa E22-400T22D（两块板各一个）

### 板1 上的 LoRa —— 走 USART3（PB10/PB11）

板1 有一个专用座 **P6（Header 4）**，直接插：

| P6 针 | 板上定义 | 接模块哪个脚 |
|---|---|---|
| 1 | VCC5V | 模块 **VCC** |
| 2 | TXD3 | 模块 **RXD** ← 交叉 |
| 3 | RXD3 | 模块 **TXD** ← 交叉 |
| 4 | GND | 模块 **GND** |

**M0 / M1 怎么办**：板1 的 P6 没有引出 M0/M1，必须**飞线到 GND**。

```
模块 M0 ──┐
模块 M1 ──┴── 板1 GND（任意一个 GND 点）
```

⚠️ **M0、M1 必须都接 GND**，否则模块停在配置/休眠模式，串口数据进得去但发不出来。

**AUX**：悬空，不用接（代码里 AUX 的宏是注释掉的，驱动不管这三个脚）。

---

### 板2 上的 LoRa —— 走 USART6（PC6/PC7）

板2 **没有 LoRa 专用座**，必须飞线到 **P2 排针**上的 PC6 / PC7。

| 模块引脚 | 接到板2 哪里 | 说明 |
|---|---|---|
| **VCC** | 5V 或 3.3V | E22 支持 2.3~5.5V，建议用 **5V** |
| **GND** | GND | 必须共地 |
| **TXD** | **PC7**（USART6_RX） | 交叉 |
| **RXD** | **PC6**（USART6_TX） | 交叉 |
| **M0** | **GND** | 飞线 |
| **M1** | **GND** | 飞线 |
| **AUX** | 悬空 | 不用 |

⚠️ **PC6/PC7 同时是 DCMI_D0/DCMI_D1**，如果插了摄像头会冲突。

---

### LoRa 通用注意

| 项目 | 要求 |
|---|---|
| 天线 | **先接天线再上电**，空载发射会烧功放 |
| 摆放 | 天线**竖直向上**，远离金属桌面和手 |
| 供电 | 发射峰值 **120mA**，VCC 就近并 **100µF + 0.1µF** |
| 配置模式 | M1 高、M0 低（改参数时才进）；**改完必须把 M1 接回 GND** |
| 透传模式 | M0=0、M1=0（正常工作模式） |
| 参数 | 已改为 13dBm：`C0 04 01 02`，回读 `C1 04 01` |

## 二、ESP8266 ESP-01S（只有板2）

### 走 USART3（PB10/PB11）

板2 的 **P3 座已坏**，改用面包板/杜邦线直连：

| 模块丝印 | 接到板2 | 说明 |
|---|---|---|
| **3V3** | 3.3V | ⚠️ **绝对不能接 5V**，会立刻烧 |
| **GND** | GND | |
| **TXD** | **PB11**（USART3_RX） | 交叉 |
| **RXD** | **PB10**（USART3_TX） | 交叉 |
| **EN**（=CH_PD） | **3.3V** | ⚠️ 不接就永远不启动 |
| **RST** | 3.3V 或悬空 | |
| **IO0** | 悬空 | 拉低会进下载模式 |
| **IO2** | 悬空 | |

### 供电是重点

ESP-01S 发射瞬间 **200~300mA**，是整块板上最耗电的东西。

- VCC 就近并 **100µF 电解 + 0.1µF 陶瓷**
- 电源线用**短而粗**的
- 不要和传感器共用一根细杜邦线

### ESP-01S 引脚排布（2×4）

从天线朝上、金手指朝下看：

```
    ┌───天线───┐
    │ 3V3  GND │
    │ TXD  EN  │
    │ RXD  RST │
    │ IO0  IO2 │
    └──────────┘
```

⚠️ **不同厂家的丝印顺序不完全一样，一定按模块背面/正面的丝印接，不要凭记忆。**

## 三、两个模块对照

| | LoRa E22 | ESP8266 ESP-01S |
|---|---|---|
| 板1 | USART3（P6 座） | 不用 |
| 板2 | USART6（PC6/PC7） | USART3（PB10/PB11） |
| 供电 | 3.3~5V，峰值 120mA | **只能 3.3V**，峰值 300mA |
| 波特率 | 9600 8N1 | 115200（代码自动试 4 档） |
| 模式脚 | M0/M1 都接 GND | EN 接 3.3V |
| 天线 | 必须接 | 板载 PCB 天线 |

## 四、上电验证

### 板1 的 LoRa

串口应该看到：
```
[board1] boot...
E22 init=0
HCLK = 168 PCLK1=42 PCLK2=84
[board1] skeleton ready
```
之后每 2 秒 `TX_OK` +1。

### 板2 的 LoRa

```
[LORA] init ok
[MON] rx=...  ← 每 2 秒 +1 说明收到板1 的帧
```

### 板2 的 ESP8266

```
[NET] WiFi OK, IP = 192.168.x.x
[MON] ... net=1
```

## 五、常见错误对照

| 现象 | 原因 | 处理 |
|---|---|---|
| LoRa 不发（TX_OK 不涨） | M0/M1 悬空或接高 | 都接 GND |
| LoRa 发但对方不收 | TXD/RXD 没交叉 | 对调两根 |
| LoRa 距离极短 | 没接天线 / 天线贴金属 | 接天线、竖直 |
| 板2 收不到 | PC6/PC7 接反 | 对调 |
| ESP 四个波特率全无应答 | EN 没接 3.3V / 没供电 | 量 EN 和 VCC |
| ESP 扫不到但能上电 | TXD/RXD 接反 | PB10↔PB11 对调 |
| ESP 连不上 WiFi | 热点是 5G / WPA3 | 用 2.4G WPA2 |
| 插上模块后板子重启 | 供电塌陷 | 加 100µF、独立供电 |

## 六、断电检查清单

- [ ] LoRa 的 **M0、M1 都接 GND**
- [ ] LoRa 的 **TXD 接 MCU 的 RX**，RXD 接 MCU 的 TX（交叉）
- [ ] LoRa **先接天线**再上电
- [ ] ESP 的 **EN 接 3.3V**
- [ ] ESP 的 **3V3 没有接成 5V**
- [ ] ESP 的 TXD→PB11、RXD→PB10
- [ ] 两个模块的 **GND 与板子共地**
- [ ] 模块 VCC 旁有 **100µF**
