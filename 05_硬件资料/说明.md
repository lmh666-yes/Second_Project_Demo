# 项目外设资料（索引）

本目录是**工程用到的外设原始资料**，从厂商资料包里整理而来。
整理原则：**留数据手册 / 应用笔记 / 用户手册 / 原理图 / 尺寸图**，
**删掉与本工程无关的内容**（其他 MCU 平台的例程、商城链接、商品图、重复文件）。

> 整理前的完整原始包备份在 `%TEMP%\项目外设资料_备份_20261015\`（348 个文件 / 53.1 MB），
> 确认无误后可自行删除。

## 目录与对应关系

| 资料目录 | 器件 | 速查里的手册卡 | 工程里的驱动 / 引用 |
|---|---|---|---|
| `LoRa-E22/` | E22-400T22D 无线模块（工程采购型号 E22-400T22S，AT 固件） | 板1 阶段 7「LoRa 发送」/ 板2 阶段 4「LoRa 接收」 | `lora_e22.c/h`（两板都有） |
| `SHT30/` | Sensirion 温湿度 | 「SHT30 温湿度传感器」 | `sys_i2c.h` 地址 `0x44`（**外接，非本工程主用**） |
| `BMP280-BME280/` | 博世气压 | 「BMP280 气压传感器」 | `sys_bmp280.c/h`（两板都有） |
| `BH1750/` | 罗姆数字光照 | 「BH1750 光照传感器」 | `sys_bh1750.c/h`（两板都有） |
| `CCS811/` | AMS 空气质量（TVOC/eCO₂） | 「CCS811 空气质量传感器」 | `sys_ccs811.c/h`（两板都有） |
| `MQ-135/` | 半导体空气质量（模拟量） | 「MQ-135 空气质量传感器」 | 帧协议 `sys_frame.h` 内 `[10] MQ135 原始 ADC`，经 `sys_adc` 采集（板1 PF7 = ADC3_IN5，宏 `SYS_ADC_MQ135_*`） |

## 整理时删掉了什么

| 删除内容 | 说明 |
|---|---|
| 其他 MCU 平台的例程 | 8051（Keil C51，`.A51/.Uv2/.OBJ/.HEX`）、AVR（AVRMEGA16）、STC51、C8051F340、Proteus 仿真（`.DSN/.PWI/.DBK`）、STM32F103 测试工程（`CJMCU_811-测试代码`，21 MB） |
| 商城链接 | `欣薇商城.url` 之类 |
| 商品图 | `封面图.jpg`、`实物图.png` |
| 重复文件 | `xxx(1).pdf`、`xxx[6].pdf` 这类浏览器下载副产物；以及 BME280 那个自己套自己的同名目录 |

> 判断依据是**工程实际用什么**：本工程是 STM32F407 + 标准外设库，
> 上面那些例程要么是别的芯片架构，要么是别的开发环境，照抄不了，留着只会干扰查找。
> 数据手册 / 应用笔记一律保留——那些是跨平台通用的。
