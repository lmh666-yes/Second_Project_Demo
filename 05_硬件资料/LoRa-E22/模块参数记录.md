# E22-400T22D 模块参数记录

> 记录每一块 LoRa 模块的寄存器实测值，换板、换模块、怀疑"收不到"时先查这里。
> 规格书：[E22-400T22D 规格书.PDF](E22-400T22D%20规格书.PDF)（第七章 7.1 指令格式、7.2 寄存器描述）

## 一、读取方法（实测可用）

### 接线

```
CH340 (跳线 3.3V 档)          E22-400T22D
  TXD ─────────────────────→ RXD
  RXD ←───────────────────── TXD
  GND ────────────────────── GND
  3.3V ─────────────────────→ M1     配置模式：M1 = 高
  GND ──────────────────────→ M0     配置模式：M0 = 低
  VCC ← 板子 5V 或独立 5V ─── VCC    （2.3~5.5V，发射峰值约 120mA）
                               AUX → 悬空
                              天线 → 必须接上再上电
```

### 串口设置

- **9600 / 8 / 1 / 无校验 / 无流控**
- 串口助手必须用 **HEX 发送 + HEX 显示**
- **必须关掉"发送新行 / 自动加回车"** —— 多一个 `0x0D` 会被当成下一条指令的开头，写参数时可能误写相邻寄存器

### 指令

| 操作 | 发送 | 正常返回 |
|---|---|---|
| 读全部 9 个寄存器 | `C1 00 09` | `C1 00 09` + 9 字节 = **12 字节** |
| 写全部 9 个寄存器 | `C0 00 09` + 9 字节 | `C1 00 09` + 9 字节 |
| 写单个寄存器（例：信道） | `C0 05 01 17` | `C1 05 01 17` |

⚠️ 返回 `FF FF FF` = **格式错误响应**（规格书 7.1 第 6 条），说明模块活着、接线正确，只是指令不完整或写错。
⚠️ 写参数用 `C0`（掉电保存）；`C2` 是**临时寄存器，掉电失效**，不要用。
⚠️ 改 `03H`（串口/空速）后，模块立即按新波特率工作；改完必须断电重启或在透传模式生效。

## 二、板 1（检测端）模块

- 记录日期：2026-10-22
- 读取方式：CH340 + 串口助手，`C1 00 09`
- 原始回包：`C1 00 09 00 00 00 62 00 17 03 00 00`

| 地址 | 值 | 含义 | 结论 |
|---|---|---|---|
| 00H | `00` | ADDH | 地址 **0x0000** |
| 01H | `00` | ADDL | |
| 02H | `00` | NETID | 网络 ID **0** |
| 03H | `62` | `011 000 010` | 串口 **9600 8N1**；空中速率 **2.4 kbps** |
| 04H | `00` | 分包 240B / RSSI 字节关 / 22 dBm | 最大功率 |
| 05H | `17` (23) | 信道 CH=23 | **433.125 MHz** |
| 06H | `03` | 透明传输、无中继、无 LBT、WOR 接收方 | 透传 |
| 07H | `00` | CRYPT_H | 加密密钥 0 |
| 08H | `00` | CRYPT_L | **不加密** |

**判定：全新出厂默认值，未被人改过。**

### 03H 位定义（串口 + 空速）

| 位 | 含义 |
|---|---|
| `[7:5]` | 串口速率：`011`=9600（默认）、`000`=1200、`001`=2400、`010`=4800、`100`=19200、`101`=38400、`110`=57600、`111`=115200 |
| `[4:3]` | 校验：`00`=8N1（默认）、`01`=8O1、`10`=8E1 |
| `[2:0]` | 空中速率：`000`=0.3k、`001`=1.2k、`010`=2.4k（默认）、`011`=4.8k、`100`=9.6k、`101`=19.2k、`110`=38.4k、`111`=62.5k |

### 04H 位定义（分包 + 功率）

| 位 | 含义 |
|---|---|
| `[7:6]` | 分包：`00`=240B（默认）、`01`=128B、`10`=64B、`11`=32B |
| `[5]` | RSSI 字节使能：`0`=禁用（默认） |
| `[1:0]` | 发射功率：`00`=22dBm（默认）、`01`=17dBm、`10`=13dBm、`11`=10dBm |

### 05H 信道与频率

```
实际频率 = 410.125 + CH × 1 MHz
CH=23 → 433.125 MHz
```

## 四、互通判据（两块必须一致）

| 参数 | 是否必须一致 | 说明 |
|---|---|---|
| **信道 05H** | ✅ 必须 | 不同则永远收不到 |
| **空中速率 03H[2:0]** | ✅ 必须 | 不同则永远收不到 |
| **NETID 02H** | 建议一致 | 用于区分网络 |
| 地址 00H/01H | 透明传输时可不一致 | 地址 `FFFF` 为广播/监听 |
| 串口速率 03H[7:5] | 可不一致 | 但建议一致，避免数据阻塞 |

## 五、性能估算（基于当前 2.4 kbps 空速）

| 项目 | 数值 |
|---|---|
| 20 字节数据帧 + 前导/同步/包头/CRC ≈ 32 字节 | 256 bit |
| 空中传输时间 | 256 ÷ 2400 ≈ **107 ms** |
| 2 秒一帧 占空比 | ≈ 5% |
| 1 秒一帧 占空比 | ≈ 11% |
| 串口灌包时间（9600，20 字节） | 21 ms |

**注意**：串口 9600 比空中 2.4k 快 4 倍，连续发送必须等 `AUX` 空闲（`LORA_E22_WaitReady`），否则模块丢包。

## 七、踩过的坑（实测）

1. **配置模式是 M1=高、M0=低**（模式 2），不是 M0 高。老 E32 系列才是 `M1=1,M0=1`。
2. **读寄存器用 `C1`**，不是 `C2`。`C2` 是"设置临时寄存器"（写），只给地址和长度会触发格式错误 `FF FF FF`。
3. **配置模式只支持 9600 8N1**，不用扫波特率。
4. `FF FF FF` 是**格式错误响应**，不是模块坏了 —— 它恰好证明模块在线、接线正确。
5. 串口助手"发送新行"会给指令尾部多加 `0x0D`，读操作能容忍（被当不完整指令吞掉），**写操作不能容忍**。
